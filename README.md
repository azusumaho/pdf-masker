# PDFマスキングツール

## 目的
AIにPDFを渡す前に、会社名・住所・電話番号などを黒塗りして、本物の墨消しPDFにするツールです。

## 使い方
1. 「PDFファイルを選ぶ」でPDFを選ぶ
2. ページ上をドラッグして、黒塗りしたい範囲を囲む(赤枠が「黒塗り予定の範囲」)
3. 「黒塗りして書き出す」を押す
4. プレビューで、全ページの黒塗り後の見た目を**目視で確認**する
5. 「この内容で書き出す」を押すと、`元のファイル名_マスク済み.pdf` がダウンロードされる

赤枠はクリックで選んで削除できます。「元に戻す」「全て消す」も使えます。

## 特徴
- ブラウザの中だけで処理します。PDFを外部に送信・保存しません。外部API、アクセス解析、外部CDNも使いません。
- 書き出したPDFは、各ページを画像にしたものだけで作ります。元の文字データや、タイトル・作成者などのメタデータは含みません(黒い四角を重ねるだけの見せかけの墨消しではありません)。

## 制約(必ずお読みください)
- **書き出し後は、必ず目視で確認してください。** 文字の塗り残しがないか、プレビューと書き出したPDFの両方で確認してください。
- スキャン画像の自動文字認識(OCR)は、今回は対象外です。
- ロゴや印影などの画像は自動検出できません。手動で囲んで黒塗りしてください。
- 会社名・住所の自動検出は未対応です。手動で囲むか、単語リストで指定してください。
- 単語リストに短い語(例:「山田」)を入れると、その語を含む全ての箇所が候補になります。意図しない箇所まで候補になるので、候補を確認してください。
